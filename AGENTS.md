# Agent Instructions

Before changing this repository, read [`PROJECT_STATUS.md`](./PROJECT_STATUS.md).
It records active investigations, unreleased branches, external dependencies,
and the next decisions that are waiting on evidence.

Keep `PROJECT_STATUS.md` concise and update it whenever work changes one of
those facts. Do not treat the older [`context.md`](./context.md) prototype spec
as a description of the current application architecture.

Do not publish a release, merge an experimental branch, send an external
message, or ask a tester to bypass operating-system security without the
repository owner's explicit approval.
